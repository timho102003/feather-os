# Feather Documentation

Pick the guide that matches what you want to do.

## Start here

* **[getting-started.md](getting-started.md)**: install Feather, run
  the onboarding wizard, and have your first chat.
* **[architecture.md](architecture.md)**: how Feather is wired
  together, with diagrams of the agent loop, sub-agent dispatch,
  memory pipeline, skills, MCP, and compaction.

## Configure the agent

* **[providers.md](providers.md)**: pick OpenAI or OpenRouter, change
  the model, set reasoning effort, mix providers per agent.
* **[configuration.md](configuration.md)**: every knob in `app.yaml`,
  agent YAML, and the environment variables Feather reads.

## Add capabilities

* **[memory.md](memory.md)**: long-term memory backed by Qdrant and
  Gemini embeddings.
* **[skills.md](skills.md)**: drop a `SKILL.md` to teach the agent a
  new procedure.
* **[agents.md](agents.md)**: built-in sub-agents and how to write
  your own.
* **[mcp.md](mcp.md)**: connect MCP servers (Playwright, GitHub,
  internal docs, etc).
* **[scheduling.md](scheduling.md)**: make the agent run things on a
  schedule.
* **[messaging.md](messaging.md)**: chat with the agent from
  Telegram, LINE, or WhatsApp.
